# Celine | 個人自我介紹網頁 ✦

> 一句話介紹自己：「**87**」  
> 保持 87% 的幽默率真與生活熱情，剩下的留給畫筆、烤箱與顛倒世界的平衡感。

---

### 🎨 關於此專案
這是一個使用純 **HTML5 + CSS3 + Vanilla JavaScript** 打造的極簡日系米白風格個人自我介紹與履歷單頁網站（Single-page website）。

### 🧁 核心內容
- **三大日常 (Hobbies)**：
  - **Draw 畫畫**：自由線條與生活靈感速寫
  - **Bake 烘焙**：溫度、奶油與甜點的魔法時光
  - **Eat 吃貨日常**：巷弄美食地圖探索
- **特殊技能 (Skill)**：
  - **倒立 (Handstand)**：顛倒 360° 視角體驗與核心訓練（網頁中附有趣味切換互動）
- **作品與活動足跡 (Portfolio)**：
  - 週末甜點手作實驗室
  - 日常隨筆速寫微展
  - 倒立 30 天日常挑戰

### 🌿 設計特色
- **純單一檔案**：所有樣式、結構與互動皆整合在 `index.html`。
- **暖調極簡米白**：米白（`#FAF7F2`）底色搭配暖炭黑與奶茶色點綴。
- **捲動淡入動畫**：原生 `IntersectionObserver` 實現無卡頓流暢上浮淡入。
- **RWD 響應式排版**：手機、平板與桌機皆能呈現最佳視覺效果。
